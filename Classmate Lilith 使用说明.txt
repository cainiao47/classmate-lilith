Classmate Lilith 0.23.1（Windows）

版本提示：本版为 Windows v0.23.1，包含交互与阅读改进、录音分段恢复、工程搜索分页和回收站；先前 v0.23.0 仅为本地测试包，不能代替本版。macOS 下载仍为 v0.21.1，不重新构建。安装版数据保存在系统“文档”。
v0.22.2 修复 Windows 高清缩放下的文字模糊，支持按显示器缩放并自动适应窗口尺寸。需要 .NET Framework 4.7.2 或更新版本；不要单独移动或删除 Classmate Lilith.exe.config。无需将 Windows 系统缩放改成 100%。

一、启动
双击“Classmate Lilith.exe”。程序会启动本机服务并显示独立工作窗口；关闭窗口会缩到任务栏通知区域，通过托盘菜单可以重新显示或彻底退出。

二、首次设置
打开右上角“设置”，在“录音转文字”中选择千问 API 平台、腾讯云或 OpenAI，填写相应凭据并保存。默认服务为千问 API 平台。

三、转写
选择录音或视频、在线转写服务和语言，然后点击“开始转写”。程序会在本机使用 FFmpeg 增强并切分录音，再把分片发送给所选服务。当前版本不提供本地识别模式，也不需要下载模型。

四、后续流程
原始转写稿可以手工修改；确认后送入人工修订区，再执行 AI 校订、人工复核和书面化整理。待确认项可以定位原文，并在有时间轴时回听对应录音。

五、数据
安装版：API Key、任务历史、术语库、录音保存在系统“文档”中的 Classmate Lilith\data，日志在同级 logs，更新备份在 updates。使用系统识别的真实“文档”位置，兼容文档迁移至其他盘。升级保留数据；卸载时显示完整路径，可选择保留（推荐）、删除或取消，删除须再次确认。删除范围还包括当前文档目录中的窗口缓存、日志和更新备份，但不删除旧便携目录、上版旧位置的数据副本和另行制作的备份。静默卸载始终保留数据。
便携版：数据和日志仍保存在软件目录中的 data 和 logs。
工程历史支持按名称搜索和分页；删除工程会移入回收站，版本和录音保留，可从回收站恢复，不会自动清空。日志最多保留最近 20 份。
实时录音会将分段音频和文稿恢复点写入 data\live-recordings；重新打开工作台可查看未保存恢复点。只能恢复已写入的部分，不保证异常前最后几秒或硬盘故障情况下的数据；恢复不自动重启在线识别。

六、便携目录
runtime\node       本机网页服务运行环境
runtime\ffmpeg     在线转写前的音频增强与切片组件
data               用户设置、任务、录音和恢复信息
logs               最近 20 份运行日志

移动软件时请完整移动整个文件夹。不要公开分享包含个人 data 或 logs 的使用中目录；分享时应使用干净发布包。

七、安装与升级
安装版运行 Classmate-Lilith-Setup-版本号.exe。首次安装可选择旧便携版目录导入数据，复制校验后旧目录仍完整保留。
若检测到 v0.22.0 在 LocalAppData 下的旧数据且“文档”尚无新版数据，安装器会预选旧位置进行复制导入；原副本不删除。两个位置都有数据时继续使用“文档”中的数据，不自动覆盖合并。
如果系统“文档”由 OneDrive 等云盘同步，这些个人数据可能随之同步；请自行确认同步设置。更改系统文档位置前先退出程序，并确保数据文件随文档一起迁移。
右上角“检查更新”可下载新版；确认安装前会保存当前任务。录音未保存、任务正在运行或其他页面有未保存修改时，先处理后再安装。安装版可自动退出、覆盖升级并重新启动，便携版请从发布页下载安装器。
