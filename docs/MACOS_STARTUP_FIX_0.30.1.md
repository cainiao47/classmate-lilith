# Mac 0.30.1 启动修复预览

修复首次 Dock 有图标却无窗口，以及强制关闭后无法正常重新打开的启动链路。源码来自 v0.30.0，Windows 启动器及已发布 Windows 文件不变，本包不替换已有正式 Release。

- 入口显式创建 NSApplication/AppDelegate、绑定代理，并在 NSApplicationMain 整个生命周期强引用持有代理；不依赖并不存在的主 Nib/Storyboard。
- 首先创建并显示原生启动窗口，再在下一轮主循环初始化 WebView。更新器在工作台显示后启动。
- 显示/重新打开入口可重复调用，窗口不存在时补建，最小化时恢复，不把复用本机服务当成已经显示界面。
- 入口、代理绑定、启动回调、真实窗口可见性、WebView 初始化、本机服务和工作台载入均写入 launcher.log。日志目录失败时保留标准错误输出。
- 原生启动器与服务共用 CLASSMATE_DATA_DIR/CLASSMATE_LOG_DIR 绝对路径覆盖，默认用户数据位置不变，诊断使用临时目录。
- 增加独立启动诊断：启动真实 .app，核对原生窗口/工作台回调，重新打开，并强制终止原生进程后验证旧服务复用和界面恢复。诊断不开麦克风、不使用用户工程或付费模型；更新器只在诊断进程中跳过，以免更新提示干扰。

构建/诊断环境为 GitHub macOS 14 Apple Silicon，不能代替 M5/macOS 27 真机确认。临时签名和未经 Apple 公证的状态不变；系统签名策略或动态库装载失败仍应查看系统崩溃报告。
