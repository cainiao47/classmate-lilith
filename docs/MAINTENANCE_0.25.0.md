# v0.25.0 发布前维护

范围：共用服务、转写与录音恢复、工程/版本存储、工作区/复核/导出、Windows 启动器与更新助手、Mac 原生窗口与 Sparkle、构建发布脚本。基于 `work/mac-updates-review`，包含现有 Win/Mac 改动；平台代码分别维护，共用部分保持同一份源码。

## 修复清单

1. 补齐 Mac 的 confirm/alert/prompt 原生弹窗和回调；确认操作默认取消，避免删除、放弃修改等网页操作无法继续。
2. Mac 更新仅在服务接受退出请求且停止后继续替换；失败或超时保留待安装更新、解除退出锁定，允许回到工作台。
3. Windows 更新助手健康检查同时核对程序目录，避免误认同端口另一目录的同版本程序。
4. 设置局部更新和清除操作串行化，避免并发修改互相覆盖；磁盘格式、加密和凭据处理规则不变。
5. 术语读改写串行化，避免并发添加丢项。损坏或不可读术语库明确报错，禁止当成空库覆盖。
6. 共用原子文本/二进制写入在写入、同步、重命名失败时清理临时文件并保留旧目标；录音拼接失败也清理临时副本。
7. 历史版本列表响应核对请求代次和工程编号；手动版本保存固定原工程与内容快照，防止切换期间串项。
8. 过滤编号不匹配的历史版本，拒绝非对象版本和文件编号不匹配的工程，原文件保留。
9. 实时文稿在保存/归档期间再编辑时，保留或重新建立未归档恢复点，避免较新修改失去恢复入口。
10. 进度流解析/处理失败时取消上游并释放读取器，拒绝无效事件，保留已接收进度。
11. Word XML 过滤非法控制符和孤立代理字符，保留中文、正常换行和 emoji。
12. 删除软删除方案启用后已无调用者的旧录音引用检查方法；分发包补入开发与维护说明。

## 验证边界

新增并发写入、损坏文件保留、失败写入清理、迟到响应、实时保存期间编辑、数据流释放和 Word 字符回归检查。仅使用隔离目录和虚构数据。

Mac 延续用户要求，只编译并打包，不做真机交互测试。真实升级替换、系统弹窗、长时间实录/断电恢复仍需后续实际环境验证；不使用用户正式数据做安装演练。不重新设计会话令牌、Origin/WebSocket 鉴权及 API 凭据存储方案。未发布新版或推进正式更新订阅。

Mac 网页弹窗按 [Apple WKUIDelegate 接口](https://developer.apple.com/documentation/webkit/wkuidelegate/webview(_:runjavascriptconfirmpanelwithmessage:initiatedbyframe:completionhandler:))接入。
