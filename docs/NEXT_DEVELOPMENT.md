# v0.25.0 开发批次：复核栏宽、Mac 退出与更新

本批次处于开发阶段，不覆盖或重新发布 v0.24.0。用户授权推进三项工作，Mac 仅做编译与打包，不做真机或交互测试。

## 复核栏宽

正文/疑点栏以及原文/校订稿分别支持拖动分隔线；支持方向键、Shift 快速调整、Home 或双击复位。宽度设置只保存在本机界面偏好中，不写入工程。最小宽度保护正文和疑点可读性；小窗口和单栏编辑时隐藏相应分隔线，恢复对照或放大窗口后沿用偏好。

## Mac 退出保护

菜单退出、Command-Q 和系统普通退出通过同一保存检查。主工作台等待保存成功，录音、处理任务或未保存设置阻止退出。检查失败或超过 8 秒时默认返回工作台，普通退出可明确选择强制退出；更新不提供强制丢弃入口。关闭窗口仍保留后台服务。

## Mac 安装与自动更新

- 首次安装提供 DMG：把应用拖到“应用程序”。用户资料仍位于 Library 下，替换应用只替换程序。
- 使用固定版本 Sparkle 2.10.1，下载框架时校验 SHA-256，保留其许可证。自动检查更新，用户确认后下载/安装并重新启动；菜单保留手动检查入口。
- Sparkle 更新归档以 Ed25519 签名，复用既有发布密钥对应的公钥；发布私钥只读取忽略目录或 GitHub 发布机密，不进入包和仓库。更新机制不涉及 API 凭据存储。
- 安装前执行保存检查和停止本机服务；遇到未完成工作时保持更新待安装，用户完成保存后再次退出才继续安装。
- 先上传完整发布文件，再推进 HTTPS 更新订阅；没有签名私钥时禁止发布更新订阅。开发构建默认只上传工作流产物，不发布 Release。
- v0.24.0 及更早的 Mac 客户端没有更新组件，首次需要手动安装含更新组件的新版本，之后才能应用内更新。自动更新不能追溯加入旧客户端。
- 当前仍使用临时签名，尚无 Apple Developer ID 和公证；安装/更新受系统权限和 Gatekeeper 约束，不能宣称已经解决首次放行问题。

参考：[Sparkle 接入文档](https://sparkle-project.org/documentation/)、[程序化接入](https://sparkle-project.org/documentation/programmatic-setup/)、[发布签名](https://sparkle-project.org/documentation/publishing/)。
