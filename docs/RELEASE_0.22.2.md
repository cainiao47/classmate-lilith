# Classmate Lilith v0.22.2（Windows）

本次仅更新 Windows；macOS 请继续使用 [v0.21.1](https://github.com/cainiao47/classmate-lilith/releases/tag/v0.21.1)。源码已合并 v0.21.1，不能用此前误编号的本地 v0.18.0 包代替本版。

## 本次更新

- 修复高分屏文字模糊：按显示器实际缩放高清渲染，跨屏移动自动适配，无需降低 Windows 缩放比例。
- 新增 EXE 安装器、快捷方式、旧便携版数据导入，以及应用内更新检查、签名校验和覆盖升级。
- 安装版数据保存在系统“文档”下的 `Classmate Lilith\data`，日志和更新备份在同级；覆盖安装保留数据。
- 卸载时显示完整数据路径，可选择保留、删除或取消。删除需二次确认；静默卸载始终保留数据。旧便携目录和单独备份不受影响。
- 学术讲座整理支持主题章节、完整书面段落、原文核查和终审，改进 Markdown/Word 导出；不强制划分说话人。

## 下载与升级

推荐下载 **Classmate-Lilith-Setup-0.22.2.exe**。请先从托盘彻底退出旧版，再运行安装器，无需先卸载。

旧便携版首次改用安装版时，在向导中选择原便携目录导入；复制校验后保留原副本。安装版 v0.22.0 的旧数据可迁移至“文档”；若目标位置已有数据，不会自动覆盖合并。便携版仍将数据存于程序目录，移动时应保留完整文件夹。

需要 Windows 10/11 x64、.NET Framework 4.7.2 或更新版本及 WebView2 Runtime。程序尚未使用商业代码签名证书，Windows 可能显示未知发布者提示；更新清单的发布签名和 SHA-256 校验不等同于 Windows 代码签名。

如果“文档”由 OneDrive 等云盘同步，录音、任务及配置也可能被同步，请确认个人同步设置。安装前建议另行备份数据。

发布资源包括安装包、便携 ZIP、对应 SHA-256 文件和 `windows-update.json` 签名更新清单；不含用户录音、设置或发布私钥。GitHub 自动生成的 Source code 压缩包不是客户端。
