# Classmate Lilith v0.23.1（Windows）

本次仅更新 Windows。macOS 请继续使用 [v0.21.1](https://github.com/cainiao47/classmate-lilith/releases/tag/v0.21.1)。此前 v0.23.0 仅为本地阶段测试包，未正式发布，且不含全部新增功能；请使用本次重新构建的 v0.23.1。

## 本次更新

- 实时录音约每秒分段写入本机，并保存最近文稿与语境；异常中断后可从恢复入口找回已落盘部分、继续编辑并保存为工程，不自动重启在线识别。尽力修复恢复音频的封装信息，原分段保留。
- 工程历史支持按名称搜索、每页 20 项和翻页，不再只显示最近 50 个工程。
- 删除工程改为移入可恢复回收站，版本和录音保留；迟到的自动保存不会覆盖回收站，自动孤立音频清理和更新备份会保护回收站数据。
- 新建/切换工程前等待保存，历史版本恢复前自动创建独立备份；保存失败不静默切换。
- 原文或语境变化后，旧结果持续显示需更新提示，导出旧稿前需要确认。
- 整理稿增加阅读/编辑切换、章节目录和字号；提供专注模式，压缩准备区，改善正文位置、小窗口布局与设置弹窗操作。
- 补齐实时页离开保护、保存后再编辑保护和 Windows 退出前保存检查；短时进度查询失败保留原任务编号并重连，不重复提交收费任务。

## 下载与升级

推荐下载 **Classmate-Lilith-Setup-0.23.1.exe**。先保存工作，从系统托盘彻底退出旧版或临时实例，再运行安装器。已安装版可以直接覆盖升级，无需先卸载；安装版数据仍保存在系统“文档”下的 `Classmate Lilith/data`，日志和更新备份在同级。

从旧便携版改用安装版时，请在向导中选择原便携目录导入；原副本保留。临时测试实例使用独立数据目录，不会自动与正式数据合并。安装前建议另行备份重要数据。

需要 Windows 10/11 x64、.NET Framework 4.7.2 或更新版本和 WebView2 Runtime。程序尚未使用商业代码签名证书；更新清单发布签名和 SHA-256 校验不等同于 Windows 代码签名。

## 数据保护的边界

只能恢复成功写入磁盘的部分，异常前最后几秒或尚未确认的识别文字可能缺失；不保证断电、硬盘故障等情况下零丢失。恢复后请先试听并核对文稿。回收站和录音恢复点暂不自动清理；保存工程后仍可能保留原分段和拼接/修复副本，会额外占用空间。若“文档”被 OneDrive 等云盘同步，这些资料也可能同步，请确认自己的同步设置。

本版不重新设计本机会话令牌、Origin/WebSocket 鉴权或 API 凭据存储。用户数据、API 设置和发布私钥不会打入发布包。
