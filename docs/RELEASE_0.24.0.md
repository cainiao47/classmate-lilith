# Classmate Lilith v0.24.0（Windows / macOS）

本次更新 Windows 窗口和工作区交互，并于 2026-11-04 补充 macOS Apple Silicon 构建。Mac 包来自同一 `v0.24.0` 标签源码，按用户要求仅编译、打包与发布，未运行测试或真机交互验证。现有 Windows 文件保持不变。

## macOS 下载与范围

下载 **Classmate-Lilith-macOS-arm64.zip**，适用于 macOS 13 及以上、Apple Silicon（M 系列芯片）；Intel Mac 不适用。解压后将 `Classmate Lilith.app` 放入“应用程序”。替换旧版前先按 `Command-Q` 或从菜单栏选择“退出并停止服务”；已有数据仍位于 `~/Library/Application Support/Classmate Lilith/data`，替换应用不自动删除这些数据。

Mac 采用现有独立原生窗口，包含共用的四阶段工作区、复核和成稿改进；Windows 一体化顶栏与轻量侧栏属于 Windows 原生适配。Mac 包使用临时签名，未经过 Apple Developer ID 签名或公证；首次打开方式见 [macOS 安装说明](MACOS_INSTALL.md)。随包提供 ZIP 的 SHA-256 文件，构建完成不代表已经验证实际使用体验。

## 本次更新

- Windows 采用一体化顶栏、轻量侧栏和 22px 窗口圆角，保留窗口拖动、缩放、最小化、最大化及关闭至托盘；运行时不支持或加载失败时使用系统标题栏。
- 工作区分为素材导入、原文校订、人工复核、书面整理四个阶段，切换时显示对应内容。底部固定操作栏、空态和条件说明让下一步更清楚；切换阶段本身不会开始模型处理。
- 重新打开工程时按进度进入合适阶段，暂停与失败任务明确显示继续或重新处理。文字导入提供明确按钮和持续错误提示；版本恢复使用应用内确认并提前备份。
- 人工复核支持原文对照和单栏编辑；定位原文自动返回对照。面板高度适应窗口，单栏切换后编辑区进入可见位置。
- 整理稿支持加粗预览和干净的章节目录，手动清空后仍可继续编辑。分别提供复制 Markdown 和复制纯文字，复制失败会保留提示。
- 导出固定点击时的标题和正文，防止切换工程导致文件名与内容错配；防止重复提交，Word 导出增加超时和错误反馈，失败后正文保留并可重试。
- 实时页区分录音、识别与工程保存状态；结束识别缺少确认时提示核对，继续等待本机音频收尾完成，重复结束消息不覆盖已保存状态。

## 下载与升级

推荐下载 **Classmate-Lilith-Setup-0.24.0.exe**。保存工作后，在旧客户端或预览实例的系统托盘菜单选择“退出并停止服务”，再运行安装器。已安装版可直接覆盖升级，无需先卸载。安装版数据仍在系统“文档”中的 `Classmate Lilith/data`，日志和更新备份在同级。

便携用户可下载 **Classmate-Lilith-Windows-x64.zip** 并完整解压；不要仅移动 EXE。从旧便携版转安装版时可在向导选择原目录导入数据，原副本保留。此前本地 UI 预览包中的工程不会自动与正式数据合并。

需要 Windows 10/11 x64、.NET Framework 4.7.2 或更新版本及 WebView2 Runtime。更新清单使用既有发布密钥签名，安装程序尚无商业 Windows 代码签名。升级和卸载的数据保留方式延续上版。
