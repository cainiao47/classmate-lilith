# Classmate Lilith v0.25.0（开发草稿，未发布）

计划提供复核栏宽拖动、Mac 退出前保存保护，以及带 Sparkle 更新组件的 Mac DMG/ZIP，见 [开发记录](NEXT_DEVELOPMENT.md)。旧 Mac 客户端首次仍需手动安装含更新组件的新版，之后才能应用内更新。

公开下载仍为 v0.24.0，本文件不代表已经发布或完成真机验收。Mac 不做交互测试；数据目录、现有令牌/Origin/WebSocket 校验及 API 凭据存储方案保持不变。
