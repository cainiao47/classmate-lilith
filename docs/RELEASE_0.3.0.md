# Classmate Lilith v0.3.0（Windows / macOS）

本版按新的命名统一发布为 **0.3.0**，包含此前未发布的 v0.25.0 开发线全部功能及维护修复，是 v0.24.0 之后的更新，并非旧版程序。

## 升级须知

旧客户端按数值比较版本，会将 0.3.0 视为低于 0.24.0。因此 **0.24.x 用户本次需要从本发布页手动下载安装，无法依靠旧客户端的检查更新**。以后从 0.3.0 按 0.3.1、0.4.0 等顺序升级。

- Windows：下载 `Classmate-Lilith-Setup-0.3.0.exe`。保存工作，从托盘选择“退出并停止服务”后运行安装器；可以直接覆盖旧安装版，无需先卸载。用户数据仍保留在系统“文档”的 `Classmate Lilith/data`。便携用户可下载完整 Windows ZIP；迁移至安装版时在向导中选择旧目录导入。
- Mac：适用于 macOS 13+、Apple Silicon（M 系列芯片），不适用于 Intel Mac。下载 DMG，把 `Classmate Lilith.app` 拖入“应用程序”；升级前先 Command-Q 或“退出并停止服务”，再替换旧应用。资料继续保存在 `~/Library/Application Support/Classmate Lilith/data`。ZIP 同时保留。

## 新增与修复

- 复核区两处分隔线可拖动，分别调整正文/疑点及原文/校订稿宽度；支持键盘微调、双击复位与宽度记忆，小窗口保留纵向布局。
- Mac 退出前检查保存、录音、运行任务及未保存设置，更新安装共用保护机制；不能确认服务已停止时暂缓更新。
- Mac 新增 DMG 安装盘和 Sparkle 自动检查更新、确认安装及重启入口；更新 ZIP 使用既有发布密钥对应的 Ed25519 公钥校验。旧客户端首次需手动安装含更新组件的本版。
- 修复并发设置/术语写入丢失、损坏术语库被覆盖、历史版本响应串工程和保存快照混入后续修改。
- 修复录音保存期间编辑的恢复点归档、异常写入临时文件、进度流异常释放、Word 非法字符、Windows 更新目录校验及 Mac 网页确认弹窗。
- 清理已无调用者的旧逻辑并补齐分发说明。详见 [维护记录](MAINTENANCE_0.25.0.md)，该记录沿用开发阶段编号。

## 验证与边界

174 项自动回归通过；Windows 启动器/更新助手编译、高清缩放与数据路径检查通过。Mac 按要求仅编译打包，未做真机交互测试；长时实录、物理断电和真实安装升级仍需实际环境验证。源码、安装器、Windows 便携包、Mac ZIP/DMG、SHA-256、Windows 签名更新清单及 Mac 签名 appcast 一并发布。

Windows 程序尚无商业代码签名；Mac 使用临时签名，未做 Apple Developer ID 签名或公证，首次放行见 [Mac 安装说明](MACOS_INSTALL.md)。更新签名不等同于操作系统开发者签名。会话令牌、Origin/WebSocket 鉴权及 API 凭据存储方案保持不变。发布包不含用户工程、凭据、日志或发布私钥。
