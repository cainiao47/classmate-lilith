# v0.23.1：交互修订与数据保护

本说明对应 Windows v0.23.1，包含原 v0.23.0 本地测试线的界面修订和后续三项数据保护增补。Mac 下载仍为 v0.21.1，本轮不构建；不替用户安装。

## 已实现

- 新建、切换和恢复工程先等待保存成功；保存失败不切换；任务处理、文件导入和转写期间锁定工程切换及输入依赖。
- 清空、导入和接受新转写稿统一触发旧结果过期；保存状态不再承担结果过期警告。旧稿保留，导出旧结果需要确认。
- 恢复历史前自动创建独立恢复前版本；备份失败不覆盖工作记录。清理录音时同时检查历史版本引用。
- 修复 hidden 与 grid/flex 样式冲突；书面整理稿增加基础 Markdown 阅读预览、章节目录、编辑切换和字号。
- 显示当前工程与阶段；语境默认折叠，扩大正文工作区，保留暖纸色与角色，提供专注模式。语境输入继续默认等高。
- 弹窗焦点进入/循环/返回及 Esc；保存栏固定；关闭未保存设置有确认。
- 实时页区分未配置、活动录音和保存后再编辑；离开页面及更新状态覆盖活动阶段与未保存修改；主工作台往返携带原工程语境。
- Windows 普通退出先请求页面保存与检查。活动录音、任务或未保存设置会阻止普通退出；检查失败可由用户确认强制退出。安装更新沿用原先保存、活动检查与更新助手退出路径，跳过重复退出保存；仍需后续完整安装升级回归。
- 转写进度短时查询失败继续重连，保留任务编号，不重新提交收费任务。

## 后续增补：录音恢复、工程搜索分页与回收站

- 实时录音约每秒产生的音频分段按顺序写入 `data/live-recordings/<录音编号>/`，确认写入前先同步文件；首段容器头保留。文稿、语境、片段与时长通过原子检查点保存。写入失败保留内存队列、按原分段编号重试，并持续提示，不把失败显示成已落盘。
- 工作台发现未保存恢复点会显示入口；实时页可以恢复音频和最近文稿、继续编辑、导出或保存为工程。恢复不自动连接在线识别。其他窗口仍活动的录音暂不允许从列表恢复；页面异常中断后等待约 15 秒刷新，服务重启后无需等待旧活动标记。
- 尽力使用随包 FFmpeg 重新封装异常录音，补齐容器信息，不重编码、不覆盖原分段；失败时保留原始拼接音频。识别完全没有文字时也允许保存本机录音。
- 工程历史按名称搜索，每页 20 项，显示总数、页数与上一页/下一页；服务器不再截掉第 50 项之后的工程。搜索覆盖所有未删除工程，而不仅是当前页；回收站也可搜索、翻页。
- 工程删除改为移入 `data/trash`。先写入可恢复记录，再移除活动记录；版本和录音原地保留，自动孤立录音清理也会检查回收站引用。迟到的保存与版本修改不能覆盖回收站，恢复时遇到不同内容的同编号记录不会静默覆盖。更新前的元数据备份包含回收站。
- 工程回收站与录音恢复点均无自动清空或到期删除，暂不提供永久清空入口，避免误删。保存为工程后会归档恢复点，但原分段、拼接/修复副本仍占用本机空间。

限制：只能恢复已经成功写入磁盘的部分；最后几秒、尚未确认的识别文字、磁盘写入失败期间的内存数据，不保证可恢复。也不保证磁盘故障、物理断电及所有浏览器/编码器组合下零丢失。恢复后的音频应先试听。尚未完成长时真实麦克风、异常断电和 macOS 真机测试。

此前构建的 v0.23.0 安装器和已打开的临时实例**不含这三项新增功能**，不能代替本版。v0.23.1 从完整源码重新构建，不覆盖旧测试目录，也不替用户安装；请从本版发布页下载安装器。

## 验证方式

逻辑与接口测试仅使用临时目录和模拟数据；真实浏览器检查也使用隔离的示例工程，没有调用付费模型、录制麦克风或读取正式数据。原生 Windows 启动器另做编译检查。

界面检查覆盖成稿空态、标题和目录、原文变化后的持续警告、弹窗焦点和 Esc、切换前保存及较小视口布局。具体测试结果由完成本轮工作时记录，不将编译检查等同于完整安装与实录测试。

第一批记录：132 项自动测试通过，Windows 启动器编译通过。在隔离浏览器中验证了立即新建前保存、空态互斥、3 个标题/目录项、旧稿过期持续提示、焦点循环与 Esc、保存栏可见、实时页往返保留原工程。1440×900 时主编辑区顶部由约 834px 前移至约 582px；1280×800 时实时开始按钮由约 783px 前移至约 265px。均为 CSS 视口测量，不等同于所有屏幕的原生测试。

后续增补的隔离界面验证：65 个示例工程中，第四页可找到早期工程，名称搜索与回收站恢复正常。浏览器生成合成音调，不使用麦克风；未正常停止录音就离开页面，随后强制终止隔离服务再启动，成功找回 7 个已写入分段与最近文稿，并保存为工程。原始拼接音频能解码约 6.54 秒；重新封装后时长约 6.55 秒、解码无异常，原始分段哈希未改变。该例仅说明已写入前缀可恢复，不代表异常前未写入的尾部已恢复。

最终回归：145 项自动测试全部通过，包含写入中断、同分段重试、乱序/冲突拒绝、容量限制、元数据更新期间再编辑、服务重启恢复、超过 50 个工程的查询、回收站保护、版本与录音保留，以及更新前回收站备份。语法检查与差异空白检查通过。
