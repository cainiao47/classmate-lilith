## 不是只改数字就能安全升级

本地开发基于 `776a0f9`（v0.17.0），GitHub 此后还有三个提交：

- `b342079`：v0.18.0 独立桌面窗口。
- `76fcc9c`：v0.21.0 可靠性与安全修订。
- `dc377b8`：v0.21.1 项目历史改进。

上述三个提交现已整合进本地安装版开发线，同时保留安装更新、独立数据目录和学术讲座整理功能。新包从合并后的源码重新编译，而不是重命名旧 EXE。macOS 源码随合并保留，但本轮不构建或发布 Mac 包。

现有令牌、Origin/WebSocket 鉴权及 API 存储沿用 GitHub v0.21.1 的实现，不重新设计；新增更新接口遵守同一会话校验。安装版仅将可写数据、窗口缓存和启动凭据放到独立用户数据目录。
