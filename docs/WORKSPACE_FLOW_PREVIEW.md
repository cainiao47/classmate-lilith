# 四阶段工作区：本地测试说明

本轮为基于 v0.23.1 的本地开发预览，尚未创建新版本号、安装包或 GitHub 发布；不替换已安装客户端。Windows 保留轻量侧栏、一体化顶栏和 22px 窗口圆角。浏览器使用同一套四阶段内容与横向导航，macOS 尚未重新构建。

- 工作区分为素材导入、原文校订、人工复核、书面整理。切换阶段只切换视图，不复制文稿或启动处理。恢复工程按已有内容进入相应阶段。
- 素材来源区分录音文件、实时录音、已有文字。文件转写稿需主动采用；替换已有原文仍需确认。
- 各阶段提供固定操作栏、返回入口、前置条件说明和空态。未生成或过期的校订稿不能用于新整理；已有旧稿继续保留。未完成的人工复核数量持续显示，允许稍后回来处理。
- 校订稿与整理稿分别标注复制、导出入口。切换阶段收起导出菜单。复核计数与已处理状态一致。
- 保存显示空白、保存中、已保存、失败四类状态，失败提供重试；术语提示单独输入也纳入保存。日常自动保存与额外保留历史版本分别说明。
- 专注模式收起侧栏和辅助说明，提供始终可见的退出入口；较小窗口保留历史版本入口。
- 实时页分别显示录音、识别、工程保存状态。异常中断、没有结束确认或没有文字时不显示正常完成，保留持续提示。恢复录音始终提示核对。纯录音可保存，但没有文字时不能进入文字校订。

语法检查和 153 项自动测试通过。隔离浏览器验证覆盖空态导航、文字输入与缺少配置提示、设置往返、旧稿保留与过期提示、文件锁模拟保存失败及重试、复核完成计数、导出菜单收起、专注模式、1280×800 和 940×680 布局。桌面布局另通过临时宿主模拟页验证，临时页不进入分发包。

验证仅使用虚构示例工程，没有读取正式工程、调用付费模型或申请麦克风。长时真实录音、真实模型质量与完整安装升级不属于本轮验证结果。会话令牌、Origin/WebSocket 校验和 API 凭据存储方案未变更。

Windows 本地分发文件已构建；原生探针验证标题栏移除、圆角随缩放、失败回退、保存前退出握手及当前屏幕 175% 缩放。文档默认路径、自定义路径与便携数据路径检查通过。真实客户端已使用独立测试目录打开并确认界面载入；检测到用户正在操作后停止自动点击。

## 第二批：中断恢复与明确操作入口

- 重新打开暂停、失败或过期的工程时，优先进入可以继续处理的阶段。恢复同一工程的历史版本也会重新定位阶段并将焦点移至标题。
- 从磁盘恢复的“正在处理”状态转为已暂停，保留已完成内容与断点。按钮只有在素材和设置仍匹配时才显示“继续”；否则明确显示重新处理。
- 切换工程清除上一个工程尚未提交的文件选择和转写进度显示，保留当前工程已有录音关联。
- 文字导入改为明确的按钮。异步读取期间保护当前工程；读取失败、空文件或取消替换不覆盖原文。持续显示错误或成功提示，允许重新选择同一文件重试。
- 工程列表区分校订暂停、整理暂停和已有整理稿。历史版本增加“恢复此版本”按钮，面板可以滚动；恢复前使用应用内确认弹窗，默认焦点在取消，保留恢复前自动备份机制。
- 实时收尾等待服务确认最多 12 秒；缺少确认时保守标记转写可能不完整。必须等本机音频收尾完成才解除忙碌状态，重复的结束消息不覆盖已经保存的状态。

第二批最终语法检查与 158 项自动测试通过。浏览器实测包括暂停工程定位、改动成稿形式后的按钮变化与旧稿保留、恢复确认的取消和确认、同一工程恢复后切换至整理阶段、空文件导入及重新选择成功。测试继续使用独立服务和虚构工程，没有调用付费模型、录制麦克风或操作正式客户端数据。

## 第三批：长文复核、成稿阅读与导出反馈

- 人工复核可切换“原文对照”和“只看校订稿”。单栏模式扩大编辑区，切换后把编辑框带入可见位置；定位原文时自动返回对照模式。选中按钮采用深色背景，长文面板高度随窗口调整。
- 整理稿阅读视图支持现有 Markdown 子集中的加粗，目录使用干净的标题文字；代码和 HTML 字符仍按文字安全呈现。手动清空文稿后保留编辑入口，重新打开仍回到整理阶段并显示“文稿为空”。
- 整理稿分别提供“复制 Markdown”和“复制纯文字”。复制失败显示持续提示，空文稿禁用复制和导出。
- 导出时固定当次标题与内容，后续切换工程不会改变文件名或内容；区分校订稿与整理稿文件名，阻止重复提交。Word 导出提供 30 秒超时和错误反馈，失败后恢复按钮并保留文稿。成功提示为“已发起下载”，避免误报为已保存到磁盘。

第三批语法检查和 164 项自动测试通过，最后的滚动与选中样式调整另通过相关 7 项测试。隔离浏览器使用 2005 字的虚构长文验证对照切换、原文定位、加粗与目录、编辑/阅读往返、清空后重新打开，以及 1280×800、940×680 布局。最终小窗口检查无横向溢出，编辑框完整位于底部操作栏上方。复制拒绝、导出故障、超时和工程切换期间的导出快照使用自动模拟验证，没有调用真实付费服务或操作用户剪贴板。

第三批本地预览构建日期为 2026-11-04，仍基于 v0.23.1，未发布 GitHub、未生成新安装版，也未覆盖已有客户端。
